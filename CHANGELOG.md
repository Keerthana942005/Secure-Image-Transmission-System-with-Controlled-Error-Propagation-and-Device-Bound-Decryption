## Code & System Architecture Changes (`C1` -- `C18`)

- **`C1` [Authentic Benchmark Datasets]:** Replaced procedural 4-color synthetic test images with authentic continuous-tone standard benchmark datasets in `input/`:
  - `cameraman_256.png` ($256\times 256$, photographic, plain entropy 7.1507)
  - `baboon_texture_512.png` ($512\times 512$, high-frequency texture, plain entropy 7.7660)
  - `peppers_color_512.png` ($512\times 512$, chromatic gradients, plain entropy 7.5333)
  - `medical_mri_512.png` ($512\times 512$, clinical scan, plain entropy 6.7098)
  - `satellite_aerial_1024.png` ($1024\times 1024$, terrain imagery, plain entropy 7.3105)
  - `submarine.jpg` ($1199\times 460$, maritime scene, plain entropy 6.9553)
- **`C2` [800-Byte Record Framing]:** Engineered explicit record framing (`src/record_format.py`, `src/encryption.py`):
  $$\text{Record } R_i = \text{Index (4B)} \parallel \text{IV (12B)} \parallel \text{Ciphertext (768B)} \parallel \text{GHASH Tag (16B)} = 800\text{ Bytes}$$
  Eliminates whole-image tag cascade when packets are dropped or deleted in transit.
- **`C3` [Multi-Attribute AAD Binding]:** Extended Additional Authenticated Data to a 20-byte payload:
  $$\text{AAD}_i = \text{uint32}(i) \parallel \text{uint32}(H) \parallel \text{uint32}(W) \parallel \text{uint32}(N) \parallel \text{uint32}(t_{\text{epoch}})$$
  Guarantees cryptographic detection of header index tampering, dimension manipulation, stream truncation, and cross-session splicing.
- **`C4` [Defense-in-Depth Key Derivation]:** Overhauled `src/key_manager.py` with two-factor key derivation:
  - User passphrase stretched using PBKDF2-HMAC-SHA256 (600,000 iterations per NIST SP 800-132, 16B salt).
  - Secret $\text{IKM} = K_{\text{session}} \parallel P_{\text{stretched}}$ ($64\text{ bytes}$).
  - Context expansion via HKDF-SHA256 (RFC 5869) under public info `SIT-v1 || ID_device || uint32(epoch)`.
  - Passphrase strength validator enforcing $\ge 8$ characters and character diversity.
- **`C5` [Monotonic Epoch Tracking & Device Revocation List]:**
  - Implemented monotonic epoch counter validation in receiver to prevent packet replay across epochs.
  - Implemented Device Revocation List (DRL) with revocation tokens to immediately deny compromised endpoints.
  - Best-effort zeroization of ephemeral key buffers in memory.
- **`C6` [Authenticated Session Header]:** Implemented 76-byte session establishment packet:
  $$\text{SessionHeader} = \text{Magic}(4\text{B}) \parallel \text{Epoch}(4\text{B}) \parallel S_{\text{hkdf}}(16\text{B}) \parallel S_{\text{pbkdf2}}(16\text{B}) \parallel \text{DeviceID}(4\text{B}) \parallel \text{HMAC}(32\text{B})$$
  Authenticates cryptographic parameters against man-in-the-middle manipulation.
- **`C7` [Vectorized Tag-Directed Spatial Concealment]:** Rewrote `src/error_concealment.py` to implement boundary-directed inverse-distance spatial interpolation matching Eq. (10)/(11) using vectorized NumPy broadcasting (`w_top_vec`, `w_bottom_vec`, `w_left_vec`, `w_right_vec`), achieving high-speed interpolation, supporting a configurable $\tau$ threshold, returning a boolean `concealed_block_mask`, and providing OpenCV inpainting fallbacks.
- **`C8` [Standardized Cryptographic Metrics Suite]:** Created `src/image_crypto_metrics.py` implementing:
  - Shannon entropy (overall and per-channel) and theoretical maximum ($8.0000$).
  - NPCR and UACI under both fresh nonces (randomized) and fixed nonces (CTR mode single-bit flip).
  - Adjacent pixel correlation coefficients ($r_H, r_V, r_D$) with fixed-seed random pixel sampling.
  - PSNR and population-based SSIM ($SSIM(x, x) \equiv 1.0000$).
  - Pearson's Chi-Square uniformity goodness-of-fit test against critical threshold ($\chi^2_{0.05} = 293.25$).
- **`C9` [Framed and Unframed Baseline Cipher Suite]:** Implemented `src/baseline_ciphers.py` containing:
